## 5. Единственная незавершённая UI-проблема

**Файл:** `src/components/PlaceForm.tsx`  
**Только** два переключателя: «Посетить позже» и «Понравилось».

### Последняя попытка (в коде сейчас)

- оба блока в одной горизонтальной строке (`flex: 1`);
- `fontSize: 15`, `lineHeight: 19`;
- «Посетить позже» — `numberOfLines={2}`, `textBreakStrategy="simple"`;
- «Понравилось» — `numberOfLines={1}`, `textBreakStrategy="simple"`.

### Результат на реальном Android (Expo Go)

- «Посетить позже» переносится нормально (по словам);
- «Понравилось» всё ещё обрезается до вида `Понравило...`;
- подписи визуально всё ещё слишком крупные относительно полей формы.

### Предпочтительное направление для следующей сессии

Сначала изучить актуальный layout блока (ширины, `gap`, размеры Switch, padding).

Возможные шаги (не догма — сначала проверить код):

- уменьшить подписи примерно до `fontSize: 14`, `lineHeight: 17`;
- сохранить оба переключателя в одной строке;
- не обрезать «Понравилось» многоточием;
- не переносить отдельные буквы;
- при необходимости дать правому блоку чуть больше ширины;
- уменьшить лишние горизонтальные отступы вокруг Switch;
- **не менять** остальные части `PlaceForm`.

## 7. Неочевидные решения и почему они приняты

- **DD одной строкой** — чтобы целиком копировать пару из Google/Яндекс Карт;
- **«Открыть на карте»** — только сохранённый `place.dd`, иначе Android открывал «около меня» / текущую точку;
- **геопозиция телефона** — уточнение координат в edit, не подмена сохранённых координат при открытии карты;
- **карандаш убран из списка** — чтобы не конкурировали «открыть» и «редактировать»;
- **фото файлами, в SQLite пути** — офлайн MVP по PLAN/PROJECT;
- **проверка в Expo Go на Android** важнее формального отчёта TypeScript.
